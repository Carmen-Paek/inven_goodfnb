소비기한 재고관리

로그인

계정은 Supabase 대시보드 → Authentication → Users 에서 추가합니다.

사용 방법

코드 규칙 부모코드 = 상품코드 AG00229 → 자식코드 = 부모코드-소비기한 AG00229-20270401
  1. 1

    재고 확인

    상품별 카드에서 소비기한 빠른 순으로 재고가 보입니다.

    임박 D-30 이내 주의 D-90 이내 경과 소비기한 지남

    위 요약 카드를 누르면 해당 상태만 걸러 봅니다.

  2. 2

    출고 차감

    엑셀 업로드 → 출고에서 출고 엑셀을 올립니다.

    필요한 열: 상품코드 · 소비기한 · 수량 (또는 자식코드 · 수량)

    소비기한을 비우면 빠른 소비기한부터 자동 차감합니다.

  3. 3

    검증 후 반영

    미리보기에서 행마다 전 → 후 수량을 확인하고 재고에 반영을 누릅니다.

    재고 부족·없는 코드가 있으면 반영되지 않습니다. 같은 파일을 두 번 올리면 차단됩니다.

  4. 4

    입고 · 실사 · 수정

    입고: 수량을 더합니다. 새 소비기한은 자식코드가 자동으로 생깁니다.

    실사: 실제 센 수량으로 덮어씁니다.

    잘못 올렸다면 입출고 이력 → 되돌리기, 한 건만 고칠 땐 재고 행의 수정.
